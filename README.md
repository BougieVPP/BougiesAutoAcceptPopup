# BougiesAutoBuy

A lightweight World of Warcraft (**Midnight / Forever**) addon that automatically confirms Auction House purchase and commodity confirmation popups while holding a modifier key.

## 🇬🇧 English

### Features
* **Instant Popup Confirmation:** Automatically clicks "Accept" on modern Auction House (`AuctionHouseFrame`) buyout, bid, and commodity purchase dialogs (`BUYOUT_AUCTION`, `BID_AUCTION`, `CONFIRM_COMMODITY_PURCHASE`).
* **Double safety Layer:** Disabled by default, and requires holding the **Alt** key while purchasing to prevent accidental buyouts.
* **Simple Slash Commands:** Toggle the addon on or off anytime directly from the in-game chat.

### Installation
1. Download or clone this repository.
2. Place the `BougiesAutoBuy` folder into your WoW directory:
   `World of Warcraft\_retail_\Interface\AddOns\`
3. Restart the game or type `/reload` in chat.

### Usage
* `/bab on` — Enables automatic confirmation (hold **Alt** while clicking Buy/Buyout).
* `/bab off` — Disables the addon completely.
* `/bab` — Displays the current status in chat.

## 🇫🇷 Français

### Fonctionnalités
* **Validation instantanée :** Clique automatiquement sur « Accepter » lors des confirmations d'achat immédiat, d'enchère et d'achat de commodités par quantité dans l'hôtel des ventes moderne (`AuctionHouseFrame`).
* **Double sécurité :** Désactivé par défaut à la connexion et nécessite de maintenir la touche **Alt** enfoncée pour éviter tout achat accidentel.
* **Commandes simples :** Activation et désactivation rapides directement depuis le chat en jeu.

### Installation
1. Téléchargez ou clonez ce dépôt.
2. Placez le dossier `BougiesAutoBuy` dans votre répertoire WoW :
   `World of Warcraft\_retail_\Interface\AddOns\`
3. Relancez le jeu ou tapez `/reload` dans le chat.

### Utilisation
* `/bab on` — Active la validation automatique (maintenez **Alt** en cliquant sur Acheter).
* `/bab off` — Désactive complètement l'addon.
* `/bab` — Affiche le statut actuel de l'addon dans le chat.
